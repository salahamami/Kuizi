## Rules

- English for documentation; French and Arabic for product copy.
- Requirements carry IDs (`FR-*`, `NFR-*`); tickets reference them.
- Architecture changes need an ADR in `architecture/decisions/`.
- Backlog changes follow `backlog/README.md` and are synced to Jira in the same session (`../CLAUDE.md`).
- Every change of substance gets a line in `../CHANGELOG.md`.
