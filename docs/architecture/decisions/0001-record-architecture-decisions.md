# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-16

## Context

Kuizi spans ML, platform, apps and content teams. Decisions made in meetings or chats get lost, and new contributors (people and AI sessions) need the reasons behind the structure.

## Decision

Every decision that changes the architecture, a public interface, a data store or a vendor is recorded as a numbered ADR in this folder: context, decision, consequences, status (Proposed, Accepted, Superseded).

## Consequences

Decisions are reviewable in pull requests. `CLAUDE.md` requires an ADR for structural changes.
