# Brain walkthrough — دليل الدماغ

Ten short notebooks that explain, one idea at a time, how Kuizi's brain works: from the concept graph to SAINT+ and fairness. Each notebook has an explanation in English and in Arabic, runnable code on public or simulated data, and a "Remember" box. Every code cell names the concept it shows and the production ticket that will build the real version. This is ticket T238 (KK-258).

## How to run

```bash
make ml-setup   # once: Python, PyTorch, pyKT, JupyterLab
make ml-lab     # opens JupyterLab; the notebooks are in ml/notebooks/
```

Run the notebooks in order. The first one that needs ASSISTments downloads it once (64 MB) into `ml/data/`. Each notebook runs on a laptop CPU in a few minutes; the slowest (7, 8, 10) train SAINT+ and take the longest.

## The code behind the notebooks

`ml/kuizi_brain/` holds small, readable versions of everything the notebooks use:

| Module | What it contains |
| --- | --- |
| `graph.py` | The Bac Physics concept slice (French and Arabic names), topological order, weakest prerequisite, drawing |
| `data.py` | ASSISTments 2009 download and loading, the Bac Physics student simulator, split by student |
| `models.py` | Windows, one training loop for every model, IRT and cold start, BKT, DKT, SAINT+, mastery probes and attention |
| `metrics.py` | AUC, calibration table, ECE, reliability diagram |

This is teaching code: clear rather than fast. The production brain is built in T040–T049 and T052, starting from the benchmark in T040.

## Data and licences

- **ASSISTments 2009** (skill builder, corrected and collapsed): public research data of anonymous US middle-school students. Cite Feng, M., Heffernan, N. T., & Koedinger, K. R. (2009), *Addressing the assessment challenge with an online system that tutors as it assesses*, User Modeling and User-Adapted Interaction 19(3). Used here to learn and to benchmark only; Kuizi's production models are trained on Kuizi data (T239).
- **Simulated students**: generated by `kuizi_brain/data.py`; no real person behind them.
- **EdNet KT1** is not used: the official source was not reachable and its licence (CC BY-NC 4.0) does not allow commercial use. The T040 benchmark can add it for research if the licence allows.
- No real Kuizi student data is ever used in these notebooks or on a PC.
